## 4. 关键结论

1. **Stage-12 奖励确实改变了三个算法的行为**：
   - PPO：从“总选 TS”翻转为“总选 Small”，E2E 大降、SR 大降；
   - DQN：SR 上升 7.4pp，E2E 上升 18.4%（更偏向完成更多步）；
   - DDPG：SR 上升 2.5pp，E2E 下降 23%（更偏向低时延）；
   - SAC：SR 上升 7.5pp（0.4219 → 0.4968，**超过 Random 的 0.4932**），E2E 上升 54.7%（2224 → 3439）；
   - TD3：**完全不变**——Stage-12 每步奖励是原奖励的仿射变换（`r = A/400 + 0.0025`），Q-learning 的 argmax 在正仿射变换下不变。

2. **仍无 DRL 同时超过两个静态基线**：
   - 最高 SR（TD3 S12 / Max-Quality = 0.6157 / 0.6289）；
   - 最低 E2E（Min-Latency 2245 / SAC 2224）；
   - Stage-12 的 PPO/DQN 落在两者之间，DDPG 接近 Min-Latency 但 SR 低 3.1pp。

3. **Stage-12 奖励的副作用**：
   - PPO 的 premature_stop 升至 323（12.9%），OOB 765；
   - 终止修正 `(1−T/400)·J` 在 `J` 较高时可能奖励早停。

4. **奖励设计的本质**：
   - 原奖励 A（`−e2e/100`）优化累计成本，但使“更早失败”回报更高；
   - Stage-12（`1−e2e/100`）隐含“多走步”偏好，SR 更高但 E2E 更高；
   - 两者都不是“成功前提下最小化累计 E2E”的严格目标。
