# 10C 数据审计：泄露检查报告

- 日期：2026-10-31
- 范围：10C 训练数据（Train-Seen 教师状态 + C1 恢复状态）与 10E 推理路径
- 结论先行：**未发现训练/推理不一致或信息泄露**；逐项证据如下。

## 1. 坐标/真值泄露检查（无）

| 通道 | 检查 | 结论 |
|---|---|---|
| 当前视觉 | 俯视局部 RGB（heading 帧），不含坐标 | ✓ |
| 目标描述子 | 目标图像中心 2×2 块 layer2 特征（图像内容） | ✓ 不含坐标 |
| 历史视觉/位姿/动作 | 因果窗口 t−16..t−1 的观测、相对位姿、one-hot 动作 | ✓ |
| belief（10 维） | 09C ContinuousBelief 沿轨迹因果演化；初始化来自候选库嵌入与目标图像嵌入的相似度（图像匹配），更新来自 C1 视觉测量 + Kalman | ✓ 不含真实目标坐标 |
| match（5 维） | 本步 C1 匹配输出（图像匹配结果） | ✓ |
| 标签 | 教师/C1 动作（监督信号，不是输入） | ✓ |

真实目标坐标的使用位置只有两处，均为任务定义所允许：① 构建目标参考图像
（Stage 07 认定的"合理简化"，非泄露）；② 评测器计算 SR。坐标不进入模型输入。

## 2. 时间因果性检查（无未来信息）

- 历史窗口严格取 t−16..t−1（`history_block`，索引 < t）；
- belief/match 只用截至当前步的观测与信念（Kalman + 两帧门均为因果操作）；
- 无未来动作、无成功标签、无评测器信息进入特征。
- 训练标签是当前步动作——模仿学习标准设定。

## 3. 自拟合泄露（cross-fitting 论证）

用户要求重点审计："如果匹配模块使用了 Train-Seen 数据训练，必须防止同一
条训练轨迹被自己拟合后再当推理特征"。本项目的匹配模块是 **C1（09C-1）**：

- C1 匹配器**零可学习参数**（冻结 ResNet-50 余弦相关 + 亚像素质心），
  从未在 Train-Seen 上拟合任何逐状态量；
- belief 更新中的全局超参数（tau=0.875、sigma_vis_m、eta、rho、temperature）
  是在 Train-Seen 的 2,000 状态校准子集上选出的**全局标量**，性质等同
  学习率/权重衰减——不携带逐状态信息，不会造成"轨迹被自己拟合"式的过拟合；
- 恢复状态（C1 在 Train-Seen 上的闭环轨迹）同样只经过无参数 C1 与冻结
  ResNet，无逐状态拟合。

因此 **cross-fitting / out-of-fold 对本数据生成管线不适用**（无需要 out-of-fold
的对象）。约束已记录：若未来匹配模块引入可学习参数，必须 out-of-fold 生成
训练特征（写入 STATUS 备忘）。

## 4. 训练/推理一致性检查

| 项 | 训练（10C 缓存） | 推理（10E 闭环） | 一致性 |
|---|---|---|---|
| 特征提取代码 | `build_features_10c.py` 因果循环 | `run_10e.py` 同一因果循环（逐段相同逻辑） | ✓ 单语义 |
| layer2 匹配特征 | batch-1 fp32（与 09C 生产一致） | batch-1 fp32 | ✓ 完全一致 |
| layer4 当前视觉 | 训练时 batch-128 现算 | 推理时 batch-1 现算 | 见注 1 |
| layer4 历史池化 | 缓存时 batch-128 分块 | 推理时 batch-1 逐步 | 见注 1 |
| belief 超参数 | 09C 校准冻结值 | 相同 | ✓ |

**注 1（已知、可接受）**：fp16 cuDNN 按 batch 选核，batch-1 与 batch-128 的
layer4 特征有 ≤0.5 量级的绝对差异（Stage 05 已测量并接受同量级差异；
其缓存/训练同为 batch-128，仅闭环历史为 batch-1）。10E 中当前视觉与历史
池化均为 batch-1——两者相互一致；与 10C 缓存（batch-128）的差异仅影响
"缓存历史 vs 推理历史"的数值级，不影响语义。已在 Stage 05 同款问题上有
先例，本次如实记录。

### 采样协议（最终版）

逐状态均匀：episode i 配额 k_i = max(1, round(T_i × N/ΣT))，episode 内
**随机相位步长**等间隔取样（时间均匀期望，不强制端点——第一版等间隔采样
强制包含末点，把 bin 0 从 2.5% 抬到 10.8%，已修正并验证与池分布一致），
最后全局均匀降采样到恰好 N。

### 合并数据集

250,000 状态：Stop 2.8% / Forward 91.2% / 转向 6.0%。
注意：动作先验仍由 Forward 主导（教师与 C1 的自然行为），按约定不使用
类别损失加权；10E 将检验 argmax 先验问题是否被恢复状态缓解。
