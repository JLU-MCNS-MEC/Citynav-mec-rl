## 3. 明确排除（与旧契约一致 + 用户约定）

语言指令、BERT、网络状态、**真实目标坐标直接输入**、未来动作、成功标签、

## 4. 数据与采样协议

- 样本单位 = **决策状态**（不是整条轨迹）
- **逐状态均匀采样**（Stage 07 修正）：全局目标 N=200,000；episode i 的配额
  k_i = max(1, round(T_i × N/ΣT))，episode 内等间隔取 k_i 个状态，再全局
  均匀降采样到恰好 N。短轨迹不再按状态频率被过度代表（整数取整噪音除外，
  每 episode 至少 1 个状态）；距离桶按自然频率分布
- 主分布：Train-Seen 03B 教师轨迹（22,002 条，876,398 状态）
- 恢复分布（用户批准，类 DAgger）：C1 在 Train-Seen 任务上的闭环轨迹状态，
  同逐状态均匀规则取 N=50,000，标签 = C1 动作；**不使用类别损失加权**
- 验证集（10D 每 epoch 指标）：Val-Seen 教师轨迹 400 条 × 4 状态（固定、不参与训练）
- 评测（10E）：5,324 条 Val-Seen+Val-Unseen 闭环，与 06/08/09/10B 同协议

## 5. 泄露与一致性审计结论（详见 10C REPORT）

1. **无坐标泄露**：belief/match/目标描述子全部只依赖观测图像 + 目标图像 + 候选库
2. **因果性**：历史严格 t−16..t−1；belief 沿轨迹因果更新（Kalman + 门控）
3. **无自拟合泄露（cross-fitting 论证）**：C1 匹配器**零可学习参数**，
   不存在"同一条训练轨迹被自己拟合后再当推理特征"的问题；belief 的全局
   超参数（tau/sigma/eta/rho/temperature）是 Train-Seen 上校准的**全局标量**，
   与学习率/权重衰减同属超参数，不携带逐状态信息。若未来匹配模块含可学习
   参数，则必须 out-of-fold 生成特征（已在 STATUS 中作为约束记录）
4. **训练/推理一致性**：特征提取代码单源（10C 构建器 + 10E 闭环共用同一
   causal 循环实现）；缓存归一化路径与训练路径一致（沿用 Stage 05 的
   uint8→GPU→归一化单实现原则）
