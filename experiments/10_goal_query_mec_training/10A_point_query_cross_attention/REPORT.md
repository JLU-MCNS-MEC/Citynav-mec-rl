## 1. 目标

在保留 09C-1 连续目标定位（C1）框架的前提下，回答一个问题：
**在 C1 机制的基础上引入可学习组件（Point Query / Cross-Attention），
离线定位精度与置信度门控是否比 C1 更好？**

固定条件（与用户约定一致）：
- 冻结 ResNet-50（IMAGENET1K_V2），只用 **layer2** 空间特征（512×28×28）；
- 不重新训练 ResNet-50；不引入 C2 硬门控；不改变 09C-1 连续信念更新主框架；
- 不使用 Test-Unseen 调参；只跑 seed 42。

## 2. 公平性契约（v2 核心）

PQ/CA 是 C1 匹配机制的**最小替换**，只允许以下环节可学习，其余逐字节一致：

| 环节 | C1（不变） | PQ v2 | CA v2 |
|---|---|---|---|
| 目标描述子 | 中心 2×2 块均值 + L2 归一（`matching._dense_descriptor`） | **与 C1 相同** | **与 C1 相同** |
| 观测表示 | 2×2 邻域池化（`uniform_filter` nearest 语义，torch 逐位复刻） | **与 C1 相同** | **与 C1 相同** |
| 匹配图 | 余弦稠密图（28×28） | 可学习查询/值投影后的余弦图（**恒等初始化时与 C1 数值一致**） | 注意力权重图（query/key 投影 + 可学习温度） |
| 位置提取 | 峰值 + 3×3 加权亚像素质心 | **与 C1 相同**（代码逐位移植，0.00 偏差验证） | **与 C1 相同** |
| margin / 评分 | 峰值抑制 margin / 峰值分 | **与 C1 相同** | **与 C1 相同** |
| 门控 | score ≥ tau 且两帧一致 ≤10 m | 同协议重校 tau | 同协议重校 tau |

**还原性验证（已跑）**：未训练 PQ（恒等初始化）输出的匹配图与 C1 逐元素一致
（max|diff| = 1.19e-7，浮点噪声级）；目标描述子端口 1.5e-8；池化端口 2.4e-7；
峰值/质心/margin 后处理 0.00e+00。即 **PQ 严格退化到 C1**。

## 5. 结论与推荐

**10A v2 结论：在严格公平的 C1 机制替换下，CA 达到了 C1 量级的定位精度但
没有超过它（median 3.74 vs 3.27 m，P@10m 83.7% vs 87.8%），且门控更弱
（视野外误接受 23.0% vs 4.3%）；PQ 因 MSE 图监督塌陷而不可用。两者均不
满足"显著优于 C1"的替换条件，按约定保留 C1 作为正式方案进入 10B。**

要点：

1. **CA 是首个达到 C1 定位量级的可学习方法**（在 0-40 m 距离内 CA 的 MAE
   4.9 m 与 C1 3.4 m 同量级），说明"注意力权重图 + C1 峰值/质心读取"是
   有效的匹配机制。但它没有带来增益：C1 的固定中心块余弦匹配已经近乎最优。
2. **CA 的弱点是视野外误接受**（23.0%）：softmax 峰值即使目标在视野外也会
   触发高置信；训练中的全低标签未能完全抑制。这不影响 10B 结论方向（CA
   本来也未超过 C1），若未来要修，方向是视野外负样本加权或分数校准，
   但**不引入 C2 式硬门控**。
3. **PQ 塌陷是监督设计缺陷**：MSE 把 783 个非目标格推向 -1，主导梯度使整
   个余弦图压向负值，峰值分全负 → tau 校准失效（F1=0）。这不是 PQ 机制的
   证据；把监督换成与 CA 相同的 BCE（softmax 图）是修复方向，属新一轮训练，
   需用户确认后才会启动。
4. 推理耗时：CA/PQ 比 C1 快 ~30 倍（0.07-0.08 vs 2.35 ms），但共享的
   特征提取 1.42 ms 使总耗时差异很小（1.49 vs 3.77 ms/状态）。

**10B 建议**：C1 直接复用 09C-1 已有 5,324 条 journal；CA 因离线质量接近
C1，可加跑 5,324 条闭环验证（~2 小时 GPU）以确认"无显著提升"的闭环证据；
PQ 待监督修复决定（需用户同意）。
