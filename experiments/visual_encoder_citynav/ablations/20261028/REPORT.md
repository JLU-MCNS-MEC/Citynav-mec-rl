- 日期：2026-10-28
- 分支：`exp/visual-encoder-ablation-20261028`
- 代码：`experiments/visual_encoder_citynav/ablations/20261028/`
- 结论摘要：**四组均完整跑完 2751 步**；E2（自适应点大小）在内部对比中综合分最高，
  但与 E1 的差距仅 0.0007，**不足以声称显著改进**；E3/E4 改变了动作行为（学会转向、
  丢失升降），综合分反而下降；四组均未超过旧基线，但旧基线使用 seed 0 与不同初始化权重，
  不是同条件对照。

## 4. 四组配置

| 组 | 唯一差异 | 配置 |
|---|---|---|
| E1 | 审计后基线 | `configs/e1.yaml` |
| E2 | `splat_radius=1`（自适应点大小） | `configs/e2.yaml` |
| E3 | 每轨迹 3 个教师步 | `configs/e3.yaml` |
| E4 | splat=1 + 3 教师步 | `configs/e4.yaml` |

共同项：seed 42、初始化权重、数据划分、2751 步、batch 8、AdamW、
`L = L_action + 0.5 L_xview + 0.5 L_retrieval`、Val-Seen 选模、Val-Unseen 仅诊断。

E2 的渲染参数由实测决定：4M 点 + splat=1 相比基线有效像素 +10.3%、耗时约 2 倍；
8M 点 + splat=1 增益可忽略（0.3307 vs 0.3295），故不采用。

- 四组并行，GPU 显存合计约 37 GB / 97.9 GB；瓶颈是 CPU 渲染
- E2/E4 的 splat 使有效像素明显高于 E1/E3（0.47 vs 0.41），与探针结论一致
- **E3/E4 的训练损失几乎不下降**（2.279→2.253），而 E1/E2 下降 0.13；
  原因是最佳步分别为 688 / 2751，且多步采样让每个 step 的样本分布更分散；
  这直接对应它们验证指标的早期见顶

## 8. 结论与建议

1. **E2（自适应点大小）是四组中唯一在动作指标和 Val-Unseen 上同时略优于 E1 的方案**，
   但综合分差距 0.0007、单种子，不能称为显著改进。
2. **E3/E4 的多步采样没有带来预期收益**：最佳 Checkpoint 提前到 688/更早，
   训练损失几乎不下降，说明在 2751 步预算下，3 倍样本摊薄了每条轨迹的重复次数，
   模型在单轮内没有充分拟合。若要继续该方向，应增加预算或降低采样倍数（如 2 步）。
3. **转向与升降的此消彼长**是当前辅助动作头的结构性限制，应优先解决
   （例如分层动作头、按类重加权，或分开的转向/升降监督），而不是继续调渲染。
4. 若要把 E2 作为新基线，建议先用 seed 11/22/33 复现，再做统计学结论。
5. Test-Unseen 继续封存，未在任何步骤读取。
