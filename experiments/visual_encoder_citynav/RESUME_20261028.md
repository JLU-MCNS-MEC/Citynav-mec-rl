## 2. 实验 A：冻结编码器 + 缩小 Token 数据集 + MEC

- 生成与训练脚本：`scripts/t5_smoke.py`
- 缓存：`data_cache/t5_frozen_1000/`
- 输出：`experiments/visual_encoder_citynav/frozen_e2_fov_pose_mec/run_20261028/`
  - 日志：`run.log`（每 100 个 episode 打印一次进度）
  - 报告：同目录下的 JSON/Markdown（脚本结束时写出）
  - MEC 权重：`data_cache/t5_frozen_1000/mec/<model>/mec.pt`
  - retriever 权重：`data_cache/t5_frozen_1000/retrieval/retriever.pt`（如已生成）
- 规模（2026-10-28 21:20 调整）：**625 条训练轨迹 ≈ 1250 个窗口**；
  Val-Seen / Val-Unseen 各 **88 条 ≈ 176 个窗口**（合计约 350 个验证窗口）。
  每个窗口 8 步，总计约 12.8k 帧。
- 并行采集：`run_parallel_tokens.sh` 用 4 个进程（train 0:209 / 209:418 /
  418:625 + val 全部）写同一分片目录；每个 episode 独立，记录顺序不变。
  语言特征先由 `--prep-only` 预计算到
  `data_cache/t5_frozen_1000/language_features.npz`，避免每个进程重复 BERT；
  采集进程用 `--reuse-retrieval` 直接加载既有 retriever，合并进程再重训
  retrieval 以保留 Recall 指标。

启动/重启命令（并行采集 + 合并训练，可重复执行以续跑）：
```bash
cd /home/20261024_1/Workspace/Citynav-mec-rl
# 0) 只需一次：预计算语言特征缓存
$HOME/miniconda3/envs/DRL_migrated/bin/python -u scripts/t5_smoke.py \
  --device cuda --seed 42 --freeze-visual-encoder \
  --encoder-checkpoint runs/visual_encoder_citynav/abl_20261028_e2_fov_pose_seed42/best_encoder.pt \
  --train-trajectories 625 --val-seen-trajectories 88 --val-unseen-trajectories 88 \
  --steps-per-trajectory 8 --cache-dir data_cache/t5_frozen_1000 \
  --output-dir experiments/visual_encoder_citynav/frozen_e2_fov_pose_mec/run_20261028 \
  --prep-only
# 1) 4 进程并行采集 → 2) 合并、写 t5_tokens.npz、训练 4 个 MEC
bash experiments/visual_encoder_citynav/frozen_e2_fov_pose_mec/run_parallel_tokens.sh
```
单进程等价命令（不并行时）：
```bash

```
**Token 生成现在支持分片断点（2026-10-28 新增）**：

- 该开关默认关闭，不改变原有行为；分片只存放在被 `.gitignore` 忽略的
  `data_cache/` 下。
- `t5_tokens.npz` 仍只在全部采集完成后写出；若中途中断，重启会复用分片，
  不会重新渲染已完成的 episode。
