# Stage 09B：动态目标信念更新与闭环验证

- 状态：**完成**
- 任务：与 Stage 06/08 **完全相同的 5,324 条**（Val-Seen 2,498 + Val-Unseen 2,826）
- 结果：**Dynamic Visual Belief SR = 47.6%**（95% CI [46.3, 48.9]），
  比 Static Top-1（44.9%）高 **+2.74 pp**（配对 95% CI [1.49, 3.99]，McNemar p = 2.0e-5），
  比 Transformer-M（23.7%）高 +23.9 pp（p ≈ 4e-173）
- 未训练任何模型；未修改 Transformer-M、Stage 04–08 的数据或权重；未使用 Test-Unseen

## 1. 实现

每个决策时刻：

1. `heading_crop` → 旋转到 north-up；
2. 冻结 ResNet-50 **layer2**（28×28×512）→ 与目标中心 2×2 特征块余弦匹配；
3. 匹配置信度 = 09A 在 **Train-Seen** 校准并冻结的门限（score ≥ 0.875）；
4. 门控：匹配置信 **且** 与当前 MAP 候选相距 ≤60 m **且** 与上一帧置信匹配相距 ≤`agree_m`；
5. 似然 `L_i = exp(-0.5 d_i²/σ²)`，在 log-space 更新 `log P ← log P + η_t (L - max)`；
6. MAP 候选 → 与 Stage 08 相同的几何控制（STOP ≤20 m、±25°、Forward 5 m、200 步）。

参数全部在 **Train-Seen** 上校准后冻结（`09b_calibration.json`）：

| 参数 | 值 | 选择依据 |
|---|---:|---|
| 先验温度 T | 0.1 | 最小化提前 STOP 率，熵 ≥ 0.15 |
| 似然 σ | 5.0 m | 同上 |
| 证据功率 η | 0.1 | 同上 |
| 相邻帧折扣 ρ | 0.7 | 同上 |
| 一致半径 agree_m | **10 m** | 同上（无门控时提前 STOP 率相同但熵更低） |

## 3. 更新质量

- 平均每个 episode **5.7 次**更新（中位 6），平均后验熵 0.717。
- 30,443 次更新事件中，**28,176 次没有改变 MAP**（24 m 候选网格量化），
  只有 2,267 次改变了 MAP：其中 **1,543 次改善（68%）**、724 次变差（32%）；
  改变时的平均误差变化 **−2.22 m**（中位 −3.62 m）。
- 更新前后的 MAP 中位误差：10.74 m → 10.54 m。
- 置信匹配（n=39,582）的定位误差中位 **3.6 m**，但 **10.7% 误差 >20 m、8.4% >40 m**——
  这是错误证据的主要来源。

## 5. 协议中的十个问题

1. **实时 RGB 能否匹配目标点？** 能：目标在 40 m 内时 layer2 中位误差 3.4–3.9 m；
   闭环中 39,582 次置信匹配的中位误差 3.6 m。
2. **目标不在视野时是否误匹配？** 会：置信匹配中 10.7% 误差 >20 m；门控把这类
   匹配的影响压低（改进 68% / 变差 32%），但没有消除。
3. **Layer2 还是 Layer3？** Layer2：09A 中位 3.6 vs 7.1 m，P@10 0.878 vs 0.769。
4. **实时视觉是否提供独立证据？** 是：2,267 次改变 MAP 的更新中 68% 改善，
   最终 SR 比静态高 2.74 pp（统计显著）。
5. **是否降低方向/距离误差？** 在**改变 MAP 的更新**上平均 −2.22 m；
   但 93% 的更新被候选网格吸收，整体中位误差只从 10.74 → 10.54 m。
6. **SR 是否超过静态 Top-1 的 44.9%？** 是：**47.6%**。
7. **过早 STOP 是否减少？** 略减：53.7% → 51.7%。
8. **身后纠偏是否改善？** 略有：目标在身后时转向率 26.0% → 28.7%。
9. **同源像素重叠是否是主要优势？** 是主要信号但很脆：RGB NCC 在 0–20 m 误差仅 0.3 m
   （几乎逐像素重合），但 40–60 m 中位误差 42 m；特征匹配（L2）在 40–60 m 仍保持 3.9 m。
   结论：同源重叠提供强信号，但不能单独依赖。
10. **是否值得引入 Goal Point Mask / Point Query / Cross-Attention？**
    数据显示两个明确瓶颈：(a) 10.7% 的置信匹配在 20 m 外（需要更好的判别/查询）；
    (b) 候选网格量化吸收了 93% 的更新（需要连续的候选/定位表示）。
    两者都指向"点查询 + 连续定位"的方向，**但需要新实验验证**，本阶段不实施。

## 6. 限制

- 更新只在匹配置信且空间一致时发生；目标在视野外时**没有负证据**（按协议），
  因此后验主要靠先验与少量正证据。
- MAP 限制在 24 m 候选网格上，定位精度被量化；这是 93% 更新不改变 MAP 的原因。
- 置信阈值来自 09A 的 Train-Seen 校准（只用了正确/错误目标图像，不含视野外的模糊情况），
  因此 10.7% 的错误置信匹配在校准集中未被充分体现。
- 动态增益（+2.74 pp）虽然显著，但绝对量不大；主要价值是证明实时视觉能提供**独立**的正向证据。
