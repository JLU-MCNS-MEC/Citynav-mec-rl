## 4. 结论

1. **没有任何算法在末期超过 Max-Quality**（0.617 / 9,482 ms）：
   PPO 的 SR 与之持平，但 $D_{sum}$ 高 32%——它已塌缩为"永远选 TS"，
   与 Max-Quality 的唯一区别是选了时延更高的那个 TS 节点。
2. **最佳值全部出现在早期**（DDPG ep200、SAC ep200、TD3 ep100），
   之后普遍回落，说明当前奖励/超参下训练在 200–600 episodes 后开始退化。
3. **动态选择确实存在**：DDPG、SAC、TD3 末期都在 3–5 个节点上分散选择，
   但分散没有转化为 SR 或时延优势。
4. **时延优势不能单独采信**：TD3 的 $D_{sum}$ 最低（10,163 ms）同时 OOB 最高
   （81/200），与 Stage 16 的失败模式一致。
5. **PPO 的问题是结构性的**：策略熵坍缩到 0.01、KL≈0、clip≈0，
   继续训练只会重复同一策略；不是"训练不够"。

## 5. 对"是否值得续训"的判断

| 算法 | 判断 | 理由 |
|---|---|---|
| PPO | ❌ 不建议直接续训 | 已塌缩为固定 TS；需先修机制（熵/advantage 尺度） |
| DQN | ⚠️ 谨慎 | 末期 0.517、最佳 0.583，震荡大，未见趋势 |
| DDPG | ✅ 可续训 | 早期达 0.617，末期选择分布合理（small+TS），有动态性 |
| TD3 | ⚠️ 谨慎 | 早期 0.617 后单调下滑，Actor 刚修复（每 2 次 Critic 更新），需观察更长 |
| SAC | ✅ 可续训 | 曾达 0.667（唯一超过 Max-Quality SR 的点），策略仍在变化 |

> 以上判断基于**单种子、Dev-60**，SR 的 ±0.05 属噪声范围；若要下正式结论，
> 至少需要 3 个种子。

## 6. 建议下一步（需审核）

1. 若继续：优先 **SAC / DDPG**，并延长到 3000–4000 episodes，
   同时记录最佳 checkpoint（而不是末期）；
2. 奖励权重：当前时延项仅占约 7%，若论文强调时延，需要重新审视 λ_L；
3. 需要多种子才能区分 0.45–0.62 之间的差异；
4. PPO 若要保留，必须改机制（恢复熵/调整 advantage 归一化），不能只加 episode。
