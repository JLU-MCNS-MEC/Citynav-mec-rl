# 实验 02：人工轨迹质量审计（Train-Seen，固定 50 m）

- 日期：2026-10-29
- 状态：**完成**
- 依赖：实验 01（固定高度与局部观测约定）
- 数据：`DATA/sbfnav-data/original_citynav/citynav_train_seen.json`（22,002 条 / 24 张地图）
- 脚本：`scripts/audit_trajectories.py`、`scripts/plot_audit.py`
- 结果：`results/train_quality.csv`、`results/summary.json`、`results/cleaned_trajectories.npz`、
  `results/selection_high.json`、`results/selection_high_medium_mixed.json`
- 未读取：`test_unseen`；Val-Seen / Val-Unseen 未参与筛选

## 1. 方法

### 1.1 固定高度投影与清理

- 保留原始水平坐标 `(x, y)`；高度统一为 `z = GROUND_LEVEL[map] + 50 m`（实验 01 的官方口径）。
- 只删除相邻水平距离 < 0.05 m 的重复点（纯垂直移动在投影后已消失），不改变路径形状；
  原始 JSON 未被修改。
- 每个 episode 的目标统一取 `target_positions[-1]`，成功半径为 **20 m 水平距离**。

### 1.2 四动作教师回放

参考官方 `LookaheadTeacherParams(lookahead=1)` 与 `interpolated_trajectory`：

1. 沿人工路径按 >5 m 间隔重采样得到 waypoints，并追加 `marker_positions[-1]`；
2. 从起点位姿（yaw 取首点的方向向量）开始，每步取**全局最近 waypoint**，看向下一个点；
3. 航向差 > 30° 时左/右转 30°，否则前进 5 m；
4. 与目标的水平距离 ≤ 20 m 时输出 STOP；超过步数上限判失败。

动作空间固定为 **Stop / Forward 5 m / TurnLeft 30° / TurnRight 30°**，不使用升降动作。

### 1.3 指标

| 指标 | 定义 |
|---|---|
| path_len_m | 清理后水平路径长度 |
| efficiency | 起点到目标的直线距离 / 路径长度（0–1） |
| detour_ratio | 路径长度 / 直线距离 |
| backtrack_ratio | 沿起点→目标方向的负向位移总和 / 路径长度 |
| turn_total_deg | 相邻点航向变化绝对值之和 |
| reversals | 超过 15° 的转向方向反转次数 |
| duplicate_ratio | 被删除的重复点 / 原始点数 |
| max_jump_m | 相邻点最大距离（异常跳跃检测） |
| outside_ratio | 落在栅格 bounds 之外的点比例 |
| nodata_ratio | 落在高程 nodata 区域（点云空洞）的点比例 |
| entered_20m | 人工路径是否曾进入目标 20 m |
| replay_success | 四动作教师能否在 20 m 内 STOP |

## 3. 分组规则与阈值（全部由分布决定）

| 阈值 | 取值 | 依据 |
|---|---:|---|
| efficiency 下限 | **0.413** | 全体 25 分位 |
| backtrack_ratio 上限 | **0.235** | 全体 90 分位 |
| turn_total 上限 | **2,945.7°** | 全体 95 分位 |
| max_jump 上限 | **157.2 m** | 全体 99 分位（再取 max(10 m)） |
| outside_ratio 上限 | 0.01 | 轨迹应在栅格内 |
| nodata_ratio 软阈值 | 0.5 | 超过一半观测落在空洞 → 中等质量 |

分类规则：

- **低质量**：未进入 20 m、回放失败、越界 >1%、异常跳跃、路径 <20 m 或退化；
- **高质量**：低质量条件全部不触发，且 efficiency ≥ 0.413、backtrack ≤ 0.235、turn_total ≤ 2,945.7°；
- **中等质量**：其余（低效率 / 高回退 / 过度转向 / 重空洞）。

## 5. 四动作覆盖率（教师输出）

| 动作 | 总次数 | 每条平均 |
|---|---:|---:|
| Forward | 1,323,104 | 60.1 |
| TurnLeft | 439,369 | 20.0 |
| TurnRight | 438,510 | 19.9 |
| Stop | 19,059 | 0.87（成功回放各一次） |

左右转次数几乎相等（439,369 vs 438,510），说明**四动作教师的转向监督是平衡的**；
这与旧版六动作数据中转向稀少的问题不同。

## 6. 低质量与中等质量的原因（可多选）

| 组 | 原因 | 数量 | 占全体 |
|---|---|---:|---:|
| 低 | 教师回放失败 | 2,942 | 13.4% |
| 低 | 人工路径从未进入 20 m | 844 | 3.8% |
| 低 | 异常跳跃 | 220 | 1.0% |
| 低 | 路径 <20 m | 65 | 0.3% |
| 低 | 越界 >1% | 48 | 0.2% |
| 中 | 低效率 | 3,783 | 17.2% |
| 中 | 高回退 | 1,502 | 6.8% |
| 中 | 过度转向 | 616 | 2.8% |
| 中 | 重空洞（>50% nodata） | 429 | 1.9% |

回放失败的构成：2,377 条进入过 20 m 但教师无法按 30°/5 m 离散动作复现；
另有 565 条人工路径本身未进入 20 m。空洞：全体 nodata 均值 9.5%，499 条超过 50%。

## 9. 结论

1. 22,002 条 Train-Seen 中 96.2% 的人工路径能进入目标 20 m，86.6% 能被四动作教师完整重放；
   这说明**固定 50 m + 四动作**的转换在绝大多数轨迹上是可行的。
2. 质量分层主要由**路径效率、回退和教师可重放性**决定；阈值全部来自分布分位数。
3. **长轨迹质量显著更差**（高质量仅 32.8%），若训练只看总体比例，会低估长任务的覆盖缺口。
4. 四动作监督的左右转数量基本平衡，不需要类别加权。
5. 建议第一轮使用 14,237 条高质量轨迹；把 4,284 条中等轨迹保留为后续受控对照，
   而不是直接丢弃。

## 10. 限制

- 回放失败 2,377 条不一定代表人工路径错误，也可能是 30° 离散动作无法精确跟随的
  几何限制；实验 03 会用正式的四动作教师转换再核验一次。
- 阈值是 Train-Seen 自身的分位数，换数据或换动作粒度需要重算。
- 越界判定基于栅格 bounds；空洞（nodata）单独统计，不作为低质量硬条件。
- 质量筛选只用于训练集；Val-Seen / Val-Unseen 保持完整，避免“挑容易的验证轨迹”。
