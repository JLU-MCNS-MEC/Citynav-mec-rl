## 1. 输入设计（无语言、无 BERT、无网络状态）

| 输入 | 构建方式 | 维度 |
|---|---|---|
| 当前俯视局部 RGB | 以 UAV 为中心、边长 100 m（离地 50 m → 半边长 50 m）的正方形，按航向旋转到机头朝前，224×224 | 冻结 ResNet-50 输出 **7×7×2048** 空间特征 |
| 目标参考图像 | 以目标为中心、北向上、边长 96 m（与候选同尺度），224×224 | 2048 维全局嵌入 |
| 全局地图候选 | 固定网格，步长 48 m，每点 96 m × 96 m 北向上切片 | 2048 维全局嵌入；28 张开发地图共 **1,238** 个候选 |
| 目标信念 | 目标嵌入与候选嵌入的余弦匹配（top-5）+ 相对当前位姿的几何量 | **12 维** |
| 历史视觉 | 过去最多 16 步的局部观测嵌入（严格 `<t`） | 16 × 2048 |
| 历史状态 | 过去四动作 one-hot + 相对位姿（前向/左向/航向差） | 16 × 4、16 × 3 |
| 历史掩码 | 有效历史长度 `min(t,16)` | 16 |

目标参考图像可以由真实目标位置**构建**，但模型只收到图像内容与嵌入，**没有坐标/ID/距离**；
全局定位完全由“参考图像 ↔ 候选切片”的视觉匹配完成。候选位置来自固定网格，不是真实目标坐标。

## 2. 目标信念（12 维）

`[top1 相似度, top5 平均相似度, 归一化熵, top1 相对 dx/dy/距离,
top5 加权相对 dx/dy/距离, top5 位置离散度, 候选数/100, 有效位]`

所有相对量都在当前机头坐标系里计算；`belief_features()` 的签名里**没有目标坐标参数**，
测试会检查这一点。

## 3. 小规模验证（Val-Seen）

样本：等间隔抽取 40 条 Val-Seen，四动作教师成功 33 条；每条在 t=5 与 t=20 各评估一次
（共 66 个样本）。

| 指标 | 结果 |
|---|---:|
| 候选 Recall@1 / @5 / @10（48 m 内） | 1.00 / 1.00 / 1.00（48 m 与候选间距同量级，几乎必然命中） |
| 候选 Recall@1 / @5 / @10（**24 m 内**） | **0.545 / 0.758 / 0.758** |
| top1 候选到真实目标距离 均值 / 中位 | 25.3 m / 22.7 m |
| top5 加权位置距离 中位 / 24 m 内比例 | 30.8 m / 36.4% |
| 信念熵（归一化） | 0.80（较分散） |
| 目标参考编码耗时（CPU） | 0.19 s/张 |
| 验证总耗时 | 136 s |

解读：48 m 网格本身限制定位精度不超过约半个格距；24 m 内的 top1 命中 54.5%、
top5 75.8%，说明视觉匹配有效但较粗。这个信念是**引导特征**，不是唯一定位来源；
实验 05 的模型还会看到当前局部观测与历史。

## 5. 设计决策与限制

1. **目标参考与候选同尺度（96 m）**：不同尺度会让 ResNet 全局嵌入的匹配失真；
   代价是参考图像包含较多上下文，定位较粗。
2. **不构建融合 Token 缓存**：本阶段只产出管线与小样本验证。实验 05 会在训练时
   **逐 episode 编码一次**（约 70 帧），再在线拼装 16 步历史窗口，避免数 GB 缓存。
3. 24 m 定位精度可以通过更细的候选网格（24 m）或学习式匹配提升，但会把候选数
   扩大到约 5,000；留到实验 05/06 视闭环表现决定。
4. CPU 编码约 0.28 s/张；实验 05 训练需要 GPU（旧实验结束后显存释放）。

## 6. 结论

1. 管线完整：局部观测、目标参考、全局候选、目标信念、16 步因果历史、四动作映射
   全部实现并通过契约检查。
2. 视觉目标定位可用但较粗（top5 24 m 内 75.8%）；信念以引导特征形式输入模型。
3. 没有任何语言/文本/网络状态输入；目标坐标只用于构建参考图像与评估，不进入模型。
4. 可以进入实验 05 的小规模 Transformer-M 训练与过拟合诊断。
