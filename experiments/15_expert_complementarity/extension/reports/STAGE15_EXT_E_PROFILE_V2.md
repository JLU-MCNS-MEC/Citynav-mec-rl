## 3. 画像预测效果

q(s, m) = P(最终成功 | 可观测量 s, 当前专家 m, 之后固定 TS)

| 模型 | AUC | PR-AUC | Brier | ECE | 自然加权 AUC | 自然加权 Brier |
|---|---:|---:|---:|---:|---:|---:|
| Static prior | 0.500 | 0.478 | 0.248 | 0.066 | 0.500 | 0.236 |
| Confidence only | 0.500 | 0.442 | 0.347 | 0.299 | 0.616 | 0.426 |
| State only | **0.705** | **0.601** | **0.225** | 0.143 | 0.669 | 0.230 |
| State + Expert | 0.687 | 0.570 | 0.246 | 0.162 | 0.639 | 0.243 |
| State + Expert + Conf | 0.680 | 0.574 | 0.265 | 0.204 | **0.722** | **0.215** |
| State + Expert + Conf + 5 专家共识 | 0.665 | 0.553 | 0.251 | 0.170 | 0.644 | 0.235 |

- 最好的是**只用状态**（AUC 0.705）。加上专家身份、置信度、五专家共识后
  非加权指标**全部下降**，说明这些维度没有提供可学习的额外信号，反而增加了过拟合。
- 自然加权下 State+Expert+Conf 达到 0.722，但同一模型非加权只有 0.680，
  差异来自加权把少数一致状态放大——**不能据此宣称模型更好**。
- 逐专家校准（最好模型）：AUC 0.658–0.670、Brier 0.244–0.257、ECE 0.156–0.188，
  五个专家之间**几乎没有差别**。

## 4. 敏感状态识别（路由器真正需要的能力）

Dev 191 状态 / 31 敏感：

| 检测器 | AUC | PR-AUC |
|---|---:|---:|
| State only | 0.500 | 0.162 |
| State + Expert | 0.593 | 0.197 |
| State + Expert + Conf | 0.622 | 0.273 |
| State + Expert + Conf + Consensus | 0.586 | 0.218 |
| **朴素规则：首步动作种类数** | **0.673** | 0.234 |

**学出来的画像（0.62）不如零成本的共识规则（0.67）**。这条规则只需要
5 次前向（约 50 ms），不需要任何训练数据。

## 5. 路由收益上限（headroom）

| 集合 | TS 固定 | 每状态取最优专家 | 增益 |
|---|---:|---:|---:|
| Train（786 状态） | 0.363 | **0.478** | +11.6 pp |
| Dev（191 状态） | 0.445 | **0.503** | +5.8 pp |

敏感状态中"最优专家"的分布：**Small 118、Medium 56、TS 20、TM 8、Large 3**；
其中 Small 成功而 TS 失败的 85 条、TS 成功而 Small 失败的 70 条。

> 即：单步专家选择的价值确实存在（Dev +5.8 pp），且主要由 Small 提供；
> 但用当前可观测量把"该换"的状态挑出来只能到 AUC 0.67，
> 把 AUC 0.67 的检测器换成真实路由增益会远低于 +5.8 pp。

## 6. 结论

1. **长期可靠性画像在当前可观测量下信号很弱**：成功主要由状态本身（进度）决定，
   专家身份、置信度、五专家共识都没有带来增益。
2. **敏感状态可以被廉价规则部分识别**（AUC 0.67），学出来的模型反而更差，
   说明标签噪声/样本量（Dev 31 正样本）是主要瓶颈。
3. **理论上限存在**（Dev +5.8 pp），但需要更准的检测器才能兑现。
4. 下一步（E4）应该直接做**规则级闭环验证**：
   Always-Small / Always-TS / Min-Latency / Max-Quality / 共识规则路由器，
   用真实闭环 SR 与 E2E 判断"可靠性感知"是否值得进入 CMDP 状态空间；
   在得到正结果前，不建议把画像作为约束或奖励项引入 DRL。
