## F · 能耗模型与 100 任务统计

### F1. 动作时间审计

| 动作 | 几何 | 时间假设 | 状态 |
|---|---|---|---|
| Forward | 5.0 m | 1.0 m/s → **5.0 s** | 仿真假设（待校准） |
| TurnLeft/Right | 30° | 30°/s → **1.0 s** | 仿真假设（待校准） |
| Stop | — | 终止 | — |
| 编码 | — | 5.450 ms | Stage 12 |
| 通信 | 依距离 | 24–126 ms | Stage 12 |
| 推理 | 依模型 | 0.495–19.972 ms | P0 实测 |

> CityNav 原始代码只定义离散位移/角度，**没有速度/角速度**；以上为显式仿真假设，
> 不得声称为实测参数。

### F2. 推进功率（Zeng et al., IEEE TWC 2019）

```
P(v) = P0(1 + 3v²/Utip²) + Pi·sqrt(1 + v⁴/(4v0⁴)) + 0.5·d0·ρ·s·A·v³
P_hover = P0 + Pi = 168.49 W
```

| 参数 | 值 | 来源 |
|---|---:|---|
| P0 | 79.86 W | Zeng 2019 |
| Pi | 88.63 W | Zeng 2019 |
| Utip | 120 m/s | Zeng 2019 |
| v0 | 4.03 m/s | Zeng 2019 |
| d0 | 0.6 | Zeng 2019 |
| ρ | 1.225 kg/m³ | 标准大气 |
| s | 0.05 | Zeng 2019 |
| A | 0.503 m² | Zeng 2019 |
| P_enc | 15 W | **仿真假设** |
| P_tx | 0.1 W | Stage 12 |
| P_aux | 5 W | **仿真假设** |
| 电池 | 100 Wh | **仿真假设** |

### F3. 每步能耗构成

```
E_step = E_move + E_wait + E_aux
E_move = P(v) × t_move               (Forward/Turn)
E_wait = (P_hover + P_enc + P_tx) × (t_enc + t_comm + t_infer)
E_aux  = P_aux × (t_move + t_wait)
```

无重复计算：移动时用推进功率；编码/通信/推理等待期间用悬停功率 + 额外负载。

### F4. 100 任务统计（Min-Latency 基线）

| 指标 | 值 |
|---|---:|
| 任务数 / 成功数 | 100 / **44** |
| 平均 Episode 能耗 | **4367.75 J（1.21 Wh）** |
| P50 | 553.43 J（0.15 Wh） |
| P90 | 16,674.01 J（4.63 Wh） |
| P95 | 18,625.29 J（5.17 Wh） |
| 成功任务平均 | 2,951.70 J |
| 失败任务平均 | 5,480.35 J |
| 能耗分量占比 | 移动 **87.9%**、等待 9.3%、辅助 2.9% |
| 电池占用（100 Wh） | 平均 1.2%，P95 5.2% |

**重要观察**：能耗分布高度偏斜（P50 仅 553 J，均值 4368 J）。原因是大量任务在
1–2 步即提前停止或越界，能耗极低；少数长任务达 15–19 kJ。**这与 Stage 16 的
累计 E2E 分布一致（失败更早）**。

在 100 Wh 电池假设下，单任务能耗仅占 1.2%（P95 5.2%），因此若以“单任务硬预算”
建模，**预算约束在多数任务上不构成实际限制**——需要重新审视电池容量假设或
改为“多任务累计预算”。

## 当前结论与建议

1. **D1–D3 数据链路已打通**，但 100 状态规模不足以支撑画像评估；
2. **E 画像尚无可信结论**（Dev 无敏感状态、AUC 无法计算）；
3. **F 能耗模型已建立**，参数来源清晰，100 任务统计已完成；
4. **能耗分布偏斜**，电池 100 Wh 下约束过松，需要确认电池容量/约束形式；
5. **下一步建议**：
   - 扩展到 **1000 状态**（200 任务 × 5 快照）：快照 ~5 分钟，分支 ~86 分钟；
   - 按 Task ID 划分 160/40，保证 Dev 含正负样本；
   - 重新训练画像并评估敏感状态识别；
   - 在确认能耗参数（尤其电池容量与 v_forward/ω_turn）后再设计 SR/能耗约束。

**本轮未启动任何大规模 DRL 训练。**
