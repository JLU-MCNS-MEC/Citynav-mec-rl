# Stage 15-Extension · G3 双约束 CMDP 五算法对比（4000 episodes）

日期：2026-11-26
能耗模型：只含 UAV 编码 + 通信 + 等待推理悬停（`MODEL_MODE="compute"`），v = 3 m/s
预算：`B_task = 0.8 × E_MinLatency(同任务)`（相对预算）
约束：`E/B ≤ 1` 与 `SR ≥ 0.50`；Lagrangian 对偶上升，η = 0.1，λ ≤ 50
训练池：1000 个有预算参考的 Train 任务；评测：Dev 60 任务（Val-Seen 未触碰）

---

## 1. 训练收敛（最后 200 episodes 的均值）

| 算法 | SR | E/B | 累计 E2E | 能耗 | λ_E（中位/最终） | λ_SR（中位/最终） |
|---|---:|---:|---:|---:|---:|---:|
| PPO | 0.355 | 1.17 | 2418 ms | 15.1 J | 29.0 / **50.0** | 41.0 / **50.0** |
| SAC | 0.520 | 1.00 | 2718 ms | 21.5 J | 2.7 / 4.3 | 9.9 / 17.7 |
| TD3 | **0.630** | **4.72** | 3926 ms | 53.4 J | **50.0 / 50.0** | 0.0 / 0.3 |
| DQN | 0.550 | 0.86 | 3185 ms | 14.2 J | 40.8 / 35.5 | 0.4 / 0.2 |
| DDPG | 0.535 | 0.83 | 3212 ms | 13.8 J | 43.8 / 38.8 | 0.4 / 1.6 |

**λ_E 的作用可以看到**：DQN 的 E/B 从训练前 200 的 4.42 降到 0.86，DDPG 从 4.30 降到 0.83，
SAC 从 2.60 降到 1.00——约束确实把策略从"用大模型"拉回"用小模型"。
TD3 的 E/B 从头到尾在 4.7 附近，λ_E 顶到上限 50 也没有拉下来。

## 2. Dev 闭环评测（60 任务，同预算口径）

| 方法 | SR | 累计 E2E | 能耗 | E/B 均值 | 超预算比例 | 节点使用 |
|---|---:|---:|---:|---:|---:|---|
| Random | 0.450 | 3978 ms | 78.6 J | 4.24 | 85% | 均匀 |
| Min-Latency | 0.433 | **2437 ms** | 45.6 J | **1.25** | **100%** | 最近节点 |
| Max-Quality (TS) | **0.617** | 3353 ms | 48.3 J | 2.72 | 73% | TS |
| PPO | 0.333 | 2812 ms | **17.2 J** | 1.04 | 37% | 单一节点 |
| SAC | 0.500 | 2961 ms | 24.1 J | 0.88 | 42% | 分散 |
| TD3 | 0.600 | 3907 ms | 50.9 J | 2.75 | 77% | TM/Large |
| DQN | 0.500 | 3847 ms | 13.9 J | **0.62** | **20%** | Small 为主 |
| **DDPG** | **0.533** | 3445 ms | **11.4 J** | **0.58** | **18%** | Small 为主 |

> Min-Latency 的 E/B = 1.25、违约率 100% 是定义决定的：它自己的能耗就是参考值，
> 而预算是它的 0.8 倍。这条是自洽性检查，不是异常。

## 3. 结论

**1. 双约束可以同时满足，而且优于基线。**
DDPG（SR 0.533、E/B 0.58、违约 18%）和 DQN（SR 0.500、E/B 0.62、违约 20%）
**在 SR 上超过 Min-Latency（0.433）7–10 pp，同时只用它 1/4 的能耗**，
并且 80% 的任务都在预算内。这是目前所有实验里第一次出现"关联策略同时改善 SR 和能耗"。

**2. TD3 是"拿能耗换 SR"的典型。**
SR 0.600 接近 Max-Quality 的 0.617，但 E/B 2.75、违约 77%、能耗 50.9 J，
本质上等于没有能耗约束。λ_E 顶到上限 50 仍未抑制，说明对 TD3 的双 Q 目标而言，
SR 带来的回报远大于能耗惩罚（离散 TD3 的 Q 平滑也让它更容易选中高回报的 TM/Large 节点）。

**3. PPO 在这个 CMDP 上失败。**
SR 0.333、两个 λ 同时顶到 50、策略塌缩到单一节点。和 300 episodes 的表现完全一致，
说明不是训练量问题，而是 PPO 的 on-policy 更新在这个奖励尺度（−e2e/100 加上
λ 项）下学不到有效的关联策略。

**4. SAC 刚好卡在约束边界。**
SR 0.500 正好等于目标，E/B 0.88，但违约率 42%——均值达标、分布上近半数任务超标。

## 4. 必须声明的局限

1. **Dev 只有 60 个任务**，单任务 = 1.67 pp，SR 差异 ±0.05 以内都在噪声范围。
   DQN(0.500) 与 SAC(0.500) 无法区分；TD3(0.600) 与 Max-Quality(0.617) 也无法区分。
2. **单随机种子（42）**，无置信区间。
3. **相对预算的方差很大**：均值 E/B 0.88 的 SAC 有 42% 的 episode 单独超预算，
   只看均值会误判约束满足情况。
4. **TD3/PPO 的 λ 触顶**：说明约束在当前惩罚尺度下对这些算法不可强制，
   需要换约束处理方式（cost-critic、RCPO、投影），而不是继续加大 λ。

## 5. 下一步建议

1. **多种子**（至少 3 个）复现 DDPG/DQN 的结论，给出 SR 与违约率的置信区间；
2. **slack 扫描**（0.6 / 0.8 / 1.0）画 SR–能耗 Pareto 前沿，回答"约束收紧的代价"；
3. 对 TD3 引入 **cost-critic**（单独估计能耗成本）而不是标量惩罚，检验能否压住违约；
4. 把 DDPG/DQN 的关联策略与固定 TS 策略在同一批任务上做配对检验
   （McNemar + 配对 bootstrap），确认 SR 差异是否显著。
